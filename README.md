# 🚀 OpenCore Legacy Patcher 3.0 (Tahoe Edition)

Welcome to the **Tahoe Edition** of OpenCore Legacy Patcher 3.0. This is a customized, community-driven fork focused on fixing specific bugs and optimizing performance for **T2-equipped Macs** running modern macOS.

---

> [!WARNING]

* **T2 Performance Tweaks:** Custom code adjustments to stabilize CPU behaviors.
* **Bug Fixes:** Powered by community insights and Gemini AI code optimizations.

## 📥 How to Install

1. Navigate to the **[Releases](../../releases)** tab on the right side of this page.
2. Download the latest `.dmg` or `.app` file under the assets list.
3. Open the application and follow the on-screen prompts to build your OpenCore EFI.

---

## 🔧 Troubleshooting & Known Issues

* **Issue:** Device feels warm or throttles during the initial setup.  
  * *Workaround:* Allow macOS to finish background indexing (Spotlight) for 1–2 hours after installation.
* **Issue:** App crashes immediately upon launching.  
  * *Workaround:* Right-click the app, select **Open**, and bypass the Gatekeeper warning if required.
